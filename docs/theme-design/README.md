# Shopify Theme Design Project

Use this folder for every new theme design or redesign project.

Recommended files:

- `project-brief.md`
- `screenshot-analysis.md`
- `design-system.md`
- `page-architecture.md`
- `pen-dev.md`
- `migration-map.md` (redesigns)
- `implementation.md`
- `qa.md`

Suggested workflow:

New theme:
`/new-shopify-theme`

Redesign:
`/redesign-shopify-theme`

Focused stages:
`/screenshot-analysis`
`/create-design-system`
`/design-shopify-pages`
`/build-shopify-theme`
`/qa-shopify-theme`
